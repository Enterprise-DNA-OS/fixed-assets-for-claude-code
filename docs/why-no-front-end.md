# The register is the working system

A finance operator asks for the month-end charge, reviews assets missing evidence, records a transfer or drafts a disposal sheet. The commands read and change one database. Read-only HTML views make the result easy to inspect and print.

A screen adds mobile scanning, guided data entry, authenticated approval clicks, attachment upload and visual comparisons. This base has no mobile app, offline synchronisation, barcode reader or multi-user browser. It does not recreate the whole FMIS suite. It is a trusted-operator asset accounting desk.

Claude Code, Codex, OpenCode and Cursor all read the same instructions. None is required to query the database directly, and no separate agent subscription is bundled. The database remains usable without a model.

Your fields, company structure, documents and review rules can change through migrations. /customise makes a tested change. /new-view adds a read-only report. A custom screen and authenticated approval process are part of the version Enterprise DNA can build for your team.
